# JavaScript Counter App

A simple counter application I built while learning the fundamentals of JavaScript.

## About

This project was created as one of my first JavaScript projects to practice connecting JavaScript with HTML and CSS. The goal was to learn how JavaScript can interact with elements on a webpage and respond to user actions.

## What I Learned

While building this project, I practiced:

* Using JavaScript variables
* Creating and using functions
* Working with the DOM
* Adding event listeners
* Responding to button clicks
* Updating HTML content with JavaScript
* Connecting JavaScript with HTML and CSS
* Organizing a project into separate HTML, CSS, and JavaScript files

## Features

* **Increment** — increases the counter
* **Decrement** — decreases the counter
* **Reset** — returns the counter to its starting value

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project is part of my journey learning web development and JavaScript. I built it to gain hands-on experience rather than only learning JavaScript through tutorials and examples.

I plan to continue building more projects as I learn additional JavaScript concepts and web development skills.
